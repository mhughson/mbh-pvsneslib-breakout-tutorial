# What's Next

You've built a complete SNES game! Choose one small project, get it working,
and build from there.

## Expand Fakeout

- **Add power-ups:** a sticky paddle, slower ball, extra life, or multiple balls.
  Start with one new capsule type and decide how it interacts with the wide paddle.
- **Build a level editor:** move a cursor around the brick grid, choose brick
  types, and play your creation. Save a custom level in cartridge RAM.
- **Improve the graphics and sound:** create your own tiles, paddle animations,
  music, and sound effects. Give each level a different theme.
- **Add new obstacles:** moving bricks, unbreakable blocks, or a boss with weak spots.
- **Try two-player play:** give each player a paddle and decide whether they
  cooperate or compete.

## Build a game from scratch

Use what you've learned about input, game state, sprites, backgrounds, and sound:

- **Pong:** two paddles, a ball, scoring, and a simple computer opponent.
- **Snake:** a tile-based board, timed movement, food, and a growing tail.
- **Tetris-style falling blocks:** a grid, piece rotation, collisions, and
  line clearing. Begin with one piece shape before adding the rest.

Start with a playable prototype using simple graphics. Add one feature at a time,
just as you did in this tutorial.
